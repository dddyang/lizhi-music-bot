## ⚡ 极客工程成果与硬核特性

区别于网络各处零散流通、注音混乱、画质残缺的二次压缩音源与盗版视频，本项目采用全栈工程化管道完成系统考证与清洗归档：

* 💿 **35 张编年唱片全本，529 首无损曲目零错漏**：严格考据官方实体唱片年表，划分「录音室全集（9张）」、「官方现场Live全本（16张）」与「海外限定精选/巡演合辑（10张）」。
* 🎬 **74 部全量高清原画影音库**：收录 2007~2019 历年全场跨年、2025 叁缺壹吉隆坡万人演唱会全场、叁叁肆巡演官方各省纪录片、逼哥夜话全集与绝版现场单曲。
* 📝 **双轨纯净歌词工程（Dual-Track Lyrics）**：
  * **内嵌无损标签（Embedded Tags）**：529 首曲目全部完成元数据内嵌（FLAC Vorbis `LYRICS`、MP3/WAV ID3v2 `USLT`、M4A `©lyr`），原生播放器开箱即显。
  * **独立同名 `.lrc` 文件（Sidecar LRC）**：1:1 配对生成同名 UTF-8 编码 `.lrc` 歌词文本，专为**特斯拉/新能源汽车车机**、**海贝/飞傲 Hi-Fi 无损硬件**量身定制。
* 🧼 **100% 真实纯净文本，剔除乱码注音**：彻底清洗市面散落版本中的注音乱码（如 `nǐ hǎo zhèng zhōu`）与 OCR 错字，还原李志原版文学文本。
* 🤖 **硬核边缘计算 Telegram 随身点播站**：基于 `aiogram 3.x` 异步框架深度定制，常驻部署于 NanoPi R2S 软路由边缘网关，具备四大全新硬核交互能力：
  * 🎲 **随缘一曲 (Random Track)**：主界面一键抽取随机盲盒歌曲，联动李志扎心经典金句卡片与即刻点播。
  * 📝 **歌词逆向搜歌**：支持输入歌词句子（如输入“港岛妹妹”、“郑州的火车”）精准定位曲目并展示歌词高亮。
  * 🎧 **专辑频道沉浸连播**：破解私聊单曲播放断流痛点，一键直达 Telegram 频道原生时间线无缝顺畅连播整张唱片。
  * 🛡️ **局域网 NAS 自动容灾备份**：通过内核级 CIFS 协议，每日凌晨定时自动将 SQLite 数据库热备份至局域网威联通 QNAP NAS，保留 14 天历史快照，彻底杜绝 TF 卡损坏丢数据。

## 🤖 硬核随身点播助手：Telegram 智能机器人

配套的点播机器人（[@libi_music_bot](https://t.me/libi_music_bot)）专为硬核点播交互设计，已全面剔除花哨冗余逻辑，聚焦专业音频与视频控制：

* 🎛️ **随身播放器控制台**：点播任意单曲即刻呼出控制键盘，支持 `⏮️ 上一首` / `⏭️ 下一首` 自由切歌，并实时展示专辑曲目序号进度（如 `🎵 3/10`）。
* 📦 **整专连续点播**：在专辑详情页或播放界面，点击「连续听整张专辑」，机器人自动依序批量推流全专辑曲目，戴上耳机享受专辑概念完整性。
* 🔄 **同名现场版本横向对比**：智能提取歌曲核心关键词。点播《梵高先生》时，自动探测并列出曲库中其他 6 个不同时期的现场版（录音室、义乌酒吧、看见巡演、东京、吉隆坡等），一键秒切。
* 🎬 **音影深度互通联动**：点播歌曲时若关联了高清全场演唱会或现场单曲视频，控制台直接提供直通按钮，毫秒级跳转原画免下载视频。
* 🏙️ **城市地标与年代时光机**：内置 `/city`（南京、郑州、兰州、成都等）与 `/era`（5 大创作时期）专属维度检索通道。
* 🔍 **智能加权搜索引擎**：支持中文、全拼与首字母缩写检索（如 `fgxs`、`zz`、`tkzc`、`跨年`、`夜话`、`山东`），音影一体化秒级呈现。
