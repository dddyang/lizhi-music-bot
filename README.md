## ⚡ 核心典藏规模与工程特性

区别于网络零散流通、注音混乱、画质残缺的二次压缩音源，本项目采用全栈工程化管道完成系统考证与清洗归档：

* 💿 **35 张编年唱片全本，529 首母带无损零错漏**：严格考据官方实体唱片年表，划分「经典录音室全集（9张）」、「官方现场Live全本（16张）」与「海外限定精选/巡演合辑（10张）」。
* 🎬 **74 部全量高清原画影音大典**：涵盖 2007~2019 历年全场跨年、2025 叁缺壹吉隆坡万人演唱会全场、叁叁肆巡演官方各省纪录片、逼哥夜话全集与绝版现场单曲。
* 📝 **双轨纯净歌词工程（Dual-Track Lyrics）**：
  * **内嵌无损标签**：529 首曲目全部嵌入规范标签（FLAC Vorbis `LYRICS`、MP3/WAV ID3v2 `USLT`、M4A `©lyr`），播放器开箱即显。
  * **外挂独立同名 `.lrc`**：1:1 配对生成同名 UTF-8 编码歌词，专为新能源车机（特斯拉等）、Hi-Fi 播放器量身定制。
  * **100% 真实纯净文本**：彻底清洗网抓版本中的拼音注音（如 `nǐ hǎo zhèng zhōu`），还原原汁原味的文学词句。
* 🤖 **极简 Telegram 随身点播助手**：
  * 🎲 **随缘一曲**：随机盲盒，联动李志经典哲思语录卡片与即刻秒播。
  * 🔍 **秒级精准检索**：支持歌名、拼音缩写（如 `fgxs`、`zz`、`tkzc`、`跨年`）与逆向歌词搜索。
  * 🎧 **专辑沉浸连播**：一键直达频道对应唱片时间线，调用 Telegram 原生播放内核顺序连播整张专辑。
  * 🛡️ **群组轻量守护**：在交流群中仅作为入群乐迷常识答题验证员，平时静默隐身，绝不刷屏打扰。
