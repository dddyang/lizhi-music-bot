## 💎 曲库核心工程成果与特色

区别于网络各处零散流通、注音混乱、版本残缺的音源，本项目历经长达数周的系统化考证与工程化清洗：

* 💿 **33 张全本收录，零错漏孤儿**：严格对照维基百科与官方实体唱片年表，划分「经典录音室创作全集（9张）」、「官方现场Live全本（14张）」、「海外限定精选（3张）」与「巡演专场与珍稀小样（7张）」。
* 📝 **双轨纯净歌词工程（Dual-Track Lyrics）**：
  * **内嵌歌词（Embedded Tags）**：490 首曲目全部完成元数据内嵌（FLAC Vorbis `LYRICS`、MP3/WAV ID3v2 `USLT`、M4A `©lyr`），手机与流媒体软件开箱即显。
  * **独立同名 `.lrc` 文件（Sidecar LRC）**：全曲目 1:1 配对生成同名 UTF-8 编码 `.lrc` 文本文件，同级存放，专为**特斯拉/新能源汽车车载中控**、**海贝/飞傲 Hi-Fi 无损播放器**及传统车载播放系统量身定制。
* 🧼 **100% 真实纯净文本，彻底剔除注音乱码**：市面流传版本充斥拼音注音残余（如 `nǐ hǎo zhèng zhōu`）与 OCR 错字，本项目全部校对还原为李志原版标点与文学文本。
* 🖼️ **全套高清封面与年份元数据规范**：每张唱片均附带官方高清封面图，规范统一艺术家、年份、专辑标签与曲目编号。
* 📊 **深度 NLP 大数据图景**：运用自然语言处理技术对全量歌词分词提取，凝练李志 20 年创作的精神图景与地名地理版图。

## 🏷️ 双轨歌词与音频元数据工程规范

曲库执行严格的音频工程归档标准，保障全设备开箱即用的优质收听体验：

```text
曲目文件结构示范：
📁 01. 经典录音室专辑/04. 我爱南京 (2009)/
   ├── 01. 天空之城.flac        <-- 内嵌 Vorbis Comments 纯净歌词 + 高清专辑封面
   ├── 01. 天空之城.lrc         <-- 独立同名 UTF-8 编码 LRC 歌词（供车载/Hi-Fi设备）
   ├── 02. 倒影.flac
   ├── 02. 倒影.lrc
   └── cover.jpg               <-- 1:1 正方形高保真唱片封面大图
```

### 1. 元数据内嵌技术标准
* **FLAC 格式**：写入 Vorbis Comments 标准帧 `TITLE`、`ARTIST`、`ALBUM`、`DATE`、`TRACKNUMBER`，内嵌 `LYRICS` 与 `UNSYNCEDLYRICS`。
* **MP3 / WAV 格式**：写入 ID3v2.3 规范帧，歌词写入 `USLT` 帧（Encoding: UTF-8，Language: `chi`）。
* **M4A / AAC 格式**：写入 MP4 atom 标准，歌词写入 `©lyr` 标签。

### 2. 车载中控与无损播放器同名 LRC 规范
* 针对大部分新能源车机（特斯拉、蔚来、理想、小鹏等）、传统车载 USB 播放系统以及硬件无损播放器（飞傲、海贝、索尼）无法读取内嵌多行标签的痛点，为 **490 首曲目全部配对生成同名 `.lrc` 文件**。
* 纯音乐与乐器独奏曲（共 32 首）统一规范标注为 `[纯音乐，请欣赏]`，避免设备显示空歌词。
